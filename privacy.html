2.2. Локальные игровые данные: Вся информация об игровом прогрессе (уровни, внутриигровая валюта «монеты», инвентарь, изученные рецепты и модификации) формируется и хранится исключительно локально во внутренней изолированной памяти устройства пользователя в каталоге приложения. Оператор не имеет доступа к данным файлам и не передает их на удаленные серверы.

2.3. Обезличенные технические данные (через рекламный SDK): В Приложение встроен SDK показа рекламы третьей стороны — Yandex Mobile Ads (ООО «ЯНДЕКС»).   • Технические сведения об устройстве: модель, производитель, версия операционной системы, архитектура процессора, разрешение экрана и ориентация (ландшафт);

  • Сетевая информация общего характера: тип подключения (Wi-Fi/сотовая сеть), приблизительное местоположение на уровне страны/города по IP-адресу.

6. Системные разрешения Android

Для реализации заявленного функционала Приложение запрашивает исключительно необходимые разрешения:

  • android.permission.INTERNET — сетевой доступ для загрузки рекламных блоков и обновления конфигурации рекламы;
  • android.permission.ACCESS_NETWORK_STATE — проверка активности интернет-соединения перед запросом рекламы для предотвращения зависаний;
  • com.google.android.gms.permission.AD_ID — доступ к системному рекламному идентификатору для работы SDK Яндекс Рекламы в соответствии с регламентом Android.

Приложение не запрашивает разрешений на чтение контактов, хранилища фото, микрофона, камеры или SMS.
